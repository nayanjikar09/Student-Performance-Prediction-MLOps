# 🎓 Student Performance Prediction - MLOps Project

An end-to-end Machine Learning Operations (MLOps) project that predicts student math scores based on various demographic and academic features. The application features a modern web interface with a complete CI/CD pipeline, Docker containerization, and automated model training.

## ✨ Features

- **🎯 Real-time Predictions**: Enter student details and get instant math score predictions
- **🧠 Multiple ML Models**: Trains and compares 7 different regression models
- **🔄 Automated Pipeline**: End-to-end from data ingestion to model deployment
- **📊 Hyperparameter Tuning**: Automated optimization for best model performance
- **🌐 Web Interface**: User-friendly Flask application with modern UI
- **📈 Model Performance Tracking**: R² scores and model comparison
- **🐳 Docker Support**: Containerized application for easy deployment
- **🚀 CI/CD Pipeline**: Automated training and deployment with GitHub Actions
